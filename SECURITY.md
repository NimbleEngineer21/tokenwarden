# Security policy

## Supported versions

tokenwarden is pre-1.0. Only the latest release receives security fixes.

## Report a vulnerability

Do not open a public issue. Report the vulnerability through
[GitHub private vulnerability reporting](https://github.com/NimbleEngineer21/tokenwarden/security/advisories/new).

Include the affected version, the steps to reproduce, and the impact. You will
receive a response within 7 days.
